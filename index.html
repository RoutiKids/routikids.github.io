    🐙 Sincronizar via GitHub (método antigo)

    📱↔️📺 Configurar pelo celular, usar na TV

    Passo 1: toque em "Preparar" — gera o texto abaixo e já verifica se o arquivo é novo ou já existe no GitHub.

    Passo 2: toque no texto que aparecer, selecione tudo (⋯ → Selecionar tudo) e copie (⋯ → Copiar) — isso é feito à mão, é mais confiável que copiar sozinho.

    Passo 3: toque em "Ir pro GitHub" — se o arquivo já existir, cole por cima do conteúdo antigo lá.

    🔧 Avançado (opcional): sincronizar sem copiar/colar

    Preencha os dois campos abaixo pra o botão "Preparar" enviar direto pro GitHub, sem precisar copiar nem colar nada. Fica salvo só neste celular — nunca é incluído no texto exportado.

    Como gerar: github.com → sua foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Em "Repository access", escolha "Only select repositories" e selecione só este. Em "Permissions" → "Repository permissions" → "Contents" → escolha "Read and write". Gere e cole o token acima.

    Na TV: toque em "Importar de config.json" — busca esse arquivo direto do GitHub e aplica, sem digitar nada.
